#  EVATRE - Guía Inteligente de Rutas de Transporte Público `[BETA]`

> ** Estado del proyecto:** Versión **Beta** operativa para las rutas y el mapa de **Cúcuta**, con arquitectura escalable a otras ciudades.

Aplicación web desarrollada con **HTML, CSS y JavaScript** que implementa **Teoría de Grafos** para optimizar el transporte público urbano.

* **Proyecto Académico:** Materia de Matemáticas Discretas  
* **Docente:** Leydi Yaritza Martínez Pardo

##  Propósito del Proyecto
Facilita la consulta de líneas de transporte público hacia un destino específico y la visualización gráfica de su trayecto en Cúcuta.

##  Fundamentación Matemática (Teoría de Grafos)
* **Modelado de la Red:** Paraderos representados como **vértices (nodos)** y los tramos como **aristas**.
* **Estructura:** Uso de matrices de adyacencia y procesamiento en JavaScript para filtrar rutas.

##  Funcionalidades Principales
1. **Mapa Visual Interactivo:** Explora la distribución de sectores.
2. **Consulta por Destino:** Identifica busetas disponibles.
3. **Visualización del Recorrido:** Muestra la secuencia completa del trayecto.
